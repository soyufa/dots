# 스테이지 설계 · 난이도 모델

## 1. 게임 규칙 (단일 소스: `src/core/rules/GameRules.ts`)

| 규칙 | 값 | 의미 |
| :--- | :--- | :--- |
| 선 두께 `LINE_WIDTH` | 0.016 | 렌더링 두께 = 판정 두께 (보드 짧은 변 대비 정규화) |
| 선 간격 `LINE_CLEARANCE` | 0.015 | 서로 다른 선의 중심선 최소 거리 → 화면에서도 겹치지 않음 |
| 점 금지 영역 | `r + LINE_WIDTH/2` | 선의 가장자리가 다른 색 점에 닿을 수 없음 |
| 테두리 여백 | `LINE_WIDTH/2` | 선은 테두리 안쪽으로 클램핑되어 1픽셀도 넘지 않음 |
| 벽 점 | 테두리와 거리 = `r` | 점 금지 영역이 테두리까지 이어져 **점과 벽 사이로 선이 빠져나갈 수 없음** |
| 내부 점 | 테두리와 거리 ≥ `r + LINE_WIDTH` | 선이 지나갈 수 있는 확실한 틈. 애매한 틈은 생성하지 않음 |

입력 판정(`InputManager`), 클리어 판정(`GameEngine`), 렌더링(`CanvasRenderer`), 생성기·검증기가 모두 같은 값을 쓴다.

## 2. 왜 예전 스테이지는 쉬웠나

자유 곡선에서는 선이 얼마든지 휘어질 수 있으므로, **영역을 완전히 가르는 선**만이 다른 쌍을 막을 수 있다.

- 두 점이 모두 벽에 붙은 쌍(**가림벽, Chord**)만 보드를 두 영역으로 나눈다.
- 한 점만 벽에 붙었거나 두 점 모두 내부인 쌍은 끝이 열린 칼집 모양이라 다른 선이 끝을 돌아서 지나갈 수 있다.

예전 생성기는 무작위 격자 경로를 서로 무관하게 깔았다. 그래서 가림벽이 거의 없었고 (Hard 50개 중 대부분 0~2개), 모든 쌍을 직선으로 이어도 풀렸다. 게다가 선이 테두리 밖으로 `0.75r`만큼 나갈 수 있었고, 점 금지 반경도 `0.45r`에 불과했다. 그래서 벽에 붙은 점 뒤로 선이 빠져나갈 수 있었고, 점이 가림벽 역할을 하지 못했다.

## 3. 난이도 지표 (`PuzzleAnalyzer`, 위상 기반 · 정확 판정)

- **강제 우회 (forcedBends)**: (가림벽 c, 다른 쌍 p)에서 p의 두 점이 c의 *직선* 기준으로 반대편에 있는 경우의 수. 이 경우 c를 직선으로 그으면 p는 절대 연결할 수 없으므로, c는 p의 점을 감싸며 휘어야 한다.
- **감싸기 깊이 (maxWrap)**: 한 쌍을 가로막는 가림벽 수의 최댓값. k이면 k개의 벽이 겹겹이 U자로 휘어 그 쌍을 감싸야 한다.
- **trivial**: 강제 우회 0, 직선끼리 교차 0, 직선이 점을 관통하지 않음 → 모든 쌍을 직선으로 이어도 풀리는 무가치 스테이지.

`forcedBends = 0`이면 모든 가림벽을 직선으로 그어도 반드시 풀린다. `forcedBends > 0`이면 직선 가림벽으로는 반드시 실패한다. 따라서 이 지표는 휴리스틱이 아니라 정확한 판정이다.

## 4. 생성 (`PuzzleGenerator`)

1. **초점 감싸기**: 초점 쌍 X–Y를 먼저 잡는다. 가림벽마다 "직선으로는 X와 Y를 가르지만, 실제 경로는 X 바깥으로 돌아가 X를 Y 쪽에 남기는" U자로 만든다. 바깥 U부터 안쪽 U 순서로 만든다.
2. **자유 가림벽**: 경유점을 거쳐 직선에서 크게 벗어나는 가림벽을 추가한다.
3. **함정 쌍**: 같은 영역 안에 있으면서 가림벽 직선 기준으로는 최대한 많이 갈라지는 위치에 나머지 쌍을 배치한다.
4. 모든 쌍의 정답 경로를 격자에서 실제로 라우팅한다. 격자 간격이 선 간격과 점 금지 반경보다 크므로 풀이 존재가 구성적으로 보장된다.

`LevelRepository`는 스테이지마다 고정 시드로 후보를 최대 80개 생성하고 다음 순서로 고른다.
`PuzzleValidator` 통과 → 최소 요구치(강제 우회, 감싸기) 충족 → 진행도 백분위에 맞는 난이도 선택.
5의 배수 스테이지는 보스(상위 후보)이고, 그다음 스테이지는 쉬어가는 톱니형 곡선이다.

## 5. 난이도 곡선 (현재 생성 결과 평균)

| 난이도 | 쌍 | 가림벽 | 강제 우회 | 감싸기 깊이 | 격자 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Easy | 3→5 | 1→2 | 1→5 | 1→2 | 9×9 |
| Normal | 4→6 | 2→3 | 2→8 | 1→3 | 12×12 |
| Hard | 7→9 | 3→4 | 5→12 | 2→3 (사각 3) | 15×15 |

## 6. 검증

`npm run verify`가 150개 스테이지 전부에 대해 다음을 확인한다.

- 정답 경로의 게임 규칙 준수 (= 풀이 가능)
- 무가치 스테이지 0개
- 최소 난이도 요구치 충족
- 중복 배치 없음
- 난이도별 후반부 > 전반부
- 평균 점수 Easy < Normal < Hard
